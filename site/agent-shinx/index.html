Agent Shinx

A Discord bot for keeping a server up to date: live scores and standings, Formula 1 weekends, game showcases, Steam sales, previews for social media links, and an AI chat mode that runs on my own hardware.

Automatic posts

Nothing posts until a server admin picks a channel for it with /setchannel, so you only get the feeds you want.

  • F1 session and race updatesrace weekends
  • Nintendo Direct, State of Play and Xbox Showcase announcements, with reminders before they airas announced
  • Steam sales on popular titlesas they start
  • Manga and comic release announcementson release

Link previews

Post a link from X, Reddit, Instagram or TikTok and the bot replies with the post itself, so nobody has to open it. You'll see the author, the text, photos, and videos that play right in the chat. You'll also see likes, views and comments, and when it was posted, shown in your own timezone. No commands or setup needed.

  • X posts, with quote tweets, link cards, and GIFs that autoplayx.com · twitter.com
  • Reddit posts, with the subreddit, score and comment countreddit.com · redd.it
  • Instagram posts and reels, with the captioninstagram.com
  • TikTok videos (without the watermark) and photo poststiktok.com

Up to three links per message all come back in one reply. Videos are sent at the best quality that fits Discord's upload limit. Wrap a link in <> or a spoiler to skip the preview. Sensitive media is hidden behind a spoiler outside age-restricted channels. If the bot has Manage Messages in a channel, it also hides Discord's own preview of the link, so the post doesn't show twice.

Add it to your server

You need the Manage Server permission on the server you're adding it to. The bot asks for only what it uses:

  • View Channels and Read Message History — to see the commands you send it
  • Send Messages — to answer them
  • Embed Links — scores, standings and sales are sent as embeds
  • Attach Files — for charts, album artwork, and videos in link previews

It can't kick, ban, manage roles, or change anything about your server. After it joins, run /setchannel to turn on the automatic posts.
