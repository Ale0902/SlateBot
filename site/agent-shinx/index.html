Agent Shinx

A Discord bot for keeping a server up to date: live scores and standings, Formula 1 weekends, game showcases, Steam sales, a song of the day — and an AI chat mode that runs on my own hardware.

Automatic posts

Nothing posts until a server admin picks a channel for it with /setchannel, so you only get the feeds you want.

  • Song of the Daydaily, 1 pm ET
  • F1 session and race updatesrace weekends
  • Nintendo Direct, State of Play and Xbox Showcase announcements, with reminders before they airas announced
  • Steam sales on popular titlesas they start
  • Manga and comic release announcementson release

Add it to your server

You need the Manage Server permission on the server you're adding it to. The bot asks for only what it uses:

  • View Channels and Read Message History — to see the commands you send it
  • Send Messages — to answer them
  • Embed Links — scores, standings and sales are sent as embeds
  • Attach Files — for charts and album artwork

It can't kick, ban, manage roles, or change anything about your server. After it joins, run /setchannel to turn on the automatic posts.
